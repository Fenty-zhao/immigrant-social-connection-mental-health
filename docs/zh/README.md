# 线上社会连接与英国移民心理健康

**社交媒体使用在 COVID-19 前后是否具有补偿作用？**

*曼彻斯特大学 · 社会研究方法与统计学硕士毕业论文 · 2026*

## 研究简介

**当移民在现实生活中的友谊质量较低时，社交媒体能否发挥补偿作用，缓解心理健康方面的不利关联？**

我使用英国纵向家庭调查 Understanding Society（UKHLS）的两轮追踪数据研究这个问题。研究不仅关注社交媒体使用与心理健康之间的直接关系，更重点检验**调节效应（Moderation）**：社交媒体使用频率是否会改变友谊质量与心理困扰之间的关联强度。

论文使用**个体固定效应回归（Individual Fixed Effects）**、交互项及一系列扩展模型，研究同一个人随时间发生的变化，并控制不随时间变化的个体特征。

---

## 项目概览

| 项目 | 研究内容 |
| --- | --- |
| **研究对象** | 居住在英国、出生于英国以外的移民 |
| **数据来源** | Understanding Society Wave 11（2019–2020）和 Wave 14（2022–2023） |
| **最初两轮均参与的样本** | 1,592 人 |
| **主要回归模型样本** | 1,408 人；2,511 条人次观测 |
| **因变量** | GHQ-12 心理困扰评分，分数越高表示心理健康状况越差 |
| **核心变量** | 友谊质量；浏览与发布社交媒体内容的频率 |
| **核心方法** | 个体与调查轮次固定效应模型、友谊质量 × 社交媒体交互项 |
| **扩展分析** | 个体聚类稳健标准误、浏览/发布分开建模、控制变量、疫情前后交互、非线性检验 |

## 主要研究发现

**1. 友谊质量与更好的心理健康显著相关。**

课程论文的基准模型报告友谊质量系数 **β = −1.225，p < 0.001**。在这一模型中，较高的友谊质量对应较低的 GHQ-12 心理困扰评分。但这不意味着已经识别出因果效应。

**2. 没有发现社交媒体的补偿性调节作用具有统计显著性。**

核心交互模型 M2 中，友谊质量 × 社交媒体的系数为 **β = −0.131，p = 0.487**；采用个体聚类稳健标准误后，**p = 0.555**。因此，研究没有找到充分的统计证据来支持原先的社交补偿假说。

**3. 在疫情前后两轮数据的比较中，也没有发现调节效应存在显著差异。**

三重交互项在 M4 中为 **β = −0.170，p = 0.560**。这是一项调查时期比较，不能据此单独识别疫情的因果效应。

**不显著的交互结果仍然是重要发现。** 现有调查记录浏览、发布的频率，却无法充分识别线上互动究竟是否提供情感支持、是否维系了有意义的关系。
